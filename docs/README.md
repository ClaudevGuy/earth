# Earth user guide

Earth is a Solana market that treats **token standards as adapters**. SPL Token and Token-2022 are native. Any other program — including 128-bit amounts that SPL cannot hold — can be registered, listed, and pooled here.

This guide is for people using the Earth app and Earth Wallet. Start here, then jump to the topic you need.
