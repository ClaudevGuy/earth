Earth Wallet privacy policy

Last updated: 17 August 2026

Earth Wallet is a browser extension. It is a local key manager for Solana and for token programs registered as adapters (SPL Token, Token-2022, and custom programs including u128 amounts). It is not a custodial service and it does not create accounts on an Earth server.

What is stored

  • An encrypted copy of your seed phrase on this Chrome profile (password-based AES-GCM). Earth cannot read it.
  • Public wallet address, RPC URL, auto-lock setting, adopted token standards, listed contracts, and connected site origins.
  • An unlocked session key in Chrome session storage until you lock the wallet, the auto-lock timer fires, the OS locks, or you close the browser.

What is sent over the network

  • Balance and transaction requests to the Solana RPC URL you configure (default: the public Solana mainnet RPC).
  • Signed transactions you approve, to that same RPC.

The Earth website (not the wallet) can publish a token standard’s public fields — name, Earth-assigned program, kind, amount width, notes, the uploaded contract source, optional publisher address — to the Earth catalog so other users can find it, read the code, and create a contract on it. Listing your own standard burns $1,000 of $EARTH on the site; Earth deploys the program. The wallet does not upload standards; you can paste a share code locally.

Earth does not run analytics, crash reporting, or advertising. Seed phrases and passwords are never uploaded.

Connected sites

When you approve a connection, that origin may request signatures. You can forget a site in Settings. Dapp pages never receive your seed or password.

Contact

Questions about this policy can be opened as an issue on the Earth repository that ships this extension.
